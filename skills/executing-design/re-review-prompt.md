# Scoped re-review prompt template

재리뷰어에게 태스크 요구 또는 브리프 경로, 직전 발견 목록, 수정 주장 또는 리포트 경로, 수정 리뷰 패키지 경로를 넘긴다. 경로는 작업 리포 루트 기준이다. 모델을 명시한다.

## Review boundary

읽기 전용이다. 작업 트리·인덱스·브랜치를 변경하지 않는다.
직전 발견이 해소됐는지와 수정 diff가 들여온 새 파손만 확인한다. 수정하지 않은 코드를 다시 리뷰하거나 범위 밖 발견으로 루프를 연장하지 않는다.
수정 주장은 diff와 대조한다. 이미 실행한 테스트는 반복하지 않고 기존 증거가 답하지 못하는 구체적 의심만 집중 확인한다.

## Output

- **발견별 판정**: 각 발견의 ADDRESSED·NOT ADDRESSED와 파일·줄 증거.
- **새 파손**: 수정 diff의 Critical·Important·Minor 발견과 영향. 없으면 없음.
- **범위 밖 관찰**: 최종 리뷰로 넘길 사항. 태스크를 막지 않는다.
- **라운드 판정**: 열린 발견 목록 또는 전 발견 해소·새 Critical와 Important 없음.

최종 응답이 리포트다. 시도했다는 사실만으로 해소 판정을 내리지 않는다.
