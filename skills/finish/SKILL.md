# finish

## Execution contract

입력은 완료한 작업 트리와 실행한 설계·스크래치 경로다. 설계나 스크래치가 전달되지 않았으면 대화·리포에서 찾고, 원래 없는 산출물은 만들지 않는다. 있는 기록을 찾지 못했으면 그 한계를 보고한다.
커맨드는 해당 작업 리포에서 시작한다. 설계와 스크래치 경로는 그 리포 루트 기준이며, 스크래치는 `.groundwork/run/` 아래의 커밋되지 않은 실행 기록이다.
출력은 검증·잔여 문제·통합 결과와 브랜치·워크트리·스크래치의 보존 또는 정리 상태다.

## Verify the final state

`groundwork:verification-before-completion`에 따라 통합 대상의 검증 증거를 확인한다. 변경이 만든 실패는 고치고, 기존 실패나 검증 불가 범위는 구분해 보고한다.
현재 브랜치, 작업 트리 변경, 연결된 워크트리 여부와 관리 주체를 확인한다. 서브모듈을 연결된 워크트리로 오인하지 않는다.
통합 대상 브랜치는 사용자 지시·대화·리포 규약·upstream에서 확인한다. 서로 다른 대상이 가능하고 근거로 해소되지 않으면 각각 어디에 변경이 반영되는지 설명하고 묻는다.

## Report the outstanding findings

실행 스크래치의 진행 기록과 최종 리뷰에서 보류·Minor·막힘을 모두 읽어 발견·영향·판정 근거를 보고한다. 기록이 없으면 잔여 없음으로 단정하지 않는다.
사용자가 수정을 요청하면 해당 문제를 처리하고 영향을 받은 검증·리뷰를 갱신한 뒤 통합한다.

## Prepare the design document

실행한 설계 문서가 있으면 실제 결정과 일치하도록 고치고 `updated`를 오늘 날짜로 맞춘다. 날짜는 기존 frontmatter에서 교체하거나 `created` 다음에 넣으며 중복 키를 만들지 않는다. frontmatter가 없으면 생성일을 확인해 `created`·`updated`를 추가한다.
문서 변경은 머지·푸시 전에 작업 브랜치에 커밋한다. 변경이 없으면 날짜만을 위한 빈 커밋은 만들지 않는다.

## Determine the integration action

기존 사용자 지시가 통합 방법을 정했으면 수행한다. 정하지 않았으면 검증·잔여 문제를 보여준 뒤 아래 선택의 결과를 설명하고 답을 기다린다.

- **로컬 머지**: 확인한 대상 브랜치에 반영하고, 성공 뒤 에이전트가 만든 작업용 브랜치와 워크트리를 정리한다.
- **푸시하고 PR 생성**: 원격에 변경을 올려 리뷰받는다. 피드백 반영을 위해 브랜치·워크트리·스크래치를 보존한다.
- **그대로 유지**: 변경과 실행 기록을 현재 작업 위치에 남기고 사용자가 이어서 처리한다.

detached HEAD에서는 머지·푸시에 쓸 브랜치를 먼저 확보한다. 폐기는 사용자가 명시 요청했을 때만 처리하며, 삭제할 커밋·경로를 설명하고 대상이 모호하면 확인한다.

## Execute and clean up

로컬 머지는 대상 체크아웃의 기존 변경을 보호하며 `--ff-only`를 기본으로 한다. 분기가 갈라졌으면 작업 브랜치에서 충돌을 해결하고 영향을 받은 검증을 다시 수행한 뒤 통합한다. 다른 사람의 브랜치나 원격 이력을 덮어쓰지 않는다.
푸시는 확인한 원격·브랜치로 하고 PR은 리포 템플릿에 따라 변경·검증·잔여 문제를 설명한다. 거부된 푸시는 원격 상태를 조사하며 force push는 명시 지시가 있을 때만 한다.
머지 결과를 검증하고 성공한 뒤 정리한다. 제거 대상은 생성 기록으로 에이전트 소유가 확인된 작업 워크트리뿐이다. 워크트리 밖에서 제거하고, 이번 작업에서 에이전트가 만든 머지된 브랜치만 `git branch -d`로 지운다.
외부·호스트 관리 워크스페이스는 해당 환경의 종료 규칙을 따르며, 경로 이름만으로 삭제하지 않는다. 주 작업 체크아웃과 사용자의 파일은 정리 대상이 아니다.
로컬 통합이 성공하면 이번 실행에서 만든 스크래치도 정리한다. 작업 트리를 보존하는 경우 전달받은 정확한 경로가 `.groundwork/run/` 아래의 해당 실행 기록인지 확인해 그 디렉터리만 제거한다. PR·유지·미완료 통합에서는 남긴다.
