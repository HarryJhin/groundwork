# Junior-read review prompt

입력은 검토할 문서 경로와 선택적인 유형별 판정 파일이다. 격리된 독자가 수행하며 세션 요약이나 작성 배경을 받지 않는다. 링크는 이 스킬 디렉터리 기준이다.

## Apply the readability criteria

[Reader definition](SKILL.md#reader-definition)과 [Authoring norms](SKILL.md#authoring-norms)를 적용한다. 작성자는 문서에 정의되지 않은 고유 지식을 안다고 가정할 수 있지만 리뷰어는 그 앎을 근거로 쓰지 않는다.
설계의 타당성이나 문체 취향은 판정하지 않는다. 정의·참조·선행 조건이 문서와 명시된 자료만으로 해소되는지 본다. 모호한 조건어 자체의 정책 결손은 이 검토 범위 밖이다.

문서 전체의 용어·참조·조건을 확인하고, 실제 참조 위치를 검사한다. 제작 사정과 구조 설명은 삭제했을 때 적용에 빠지는 것이 있는지 별도로 확인한다. 유형별 판정 파일이 있으면 그 기준도 적용한다.
부분 수정 뒤에도 문서 전체를 확인하되 근거로 해소한 발견은 반복하지 않는다.

## Return the findings

발견마다 file:line, 문제가 되는 문구, 판독이 막히거나 오독하는 이유, 수정 제안을 반환한다. 축은 지식경계·참조해소·전방참조·서술판독·단독판독·표기체계·제작사정·구조중복 또는 유형별 판정 파일의 이름으로 표시한다.
발견이 없으면 PASS와 실제 확인한 범위를 반환한다. 검토하지 못한 범위는 밝힌다.
