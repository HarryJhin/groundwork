# Skill readability criteria

입력은 스킬 본문과 참조 파일이다. 격리된 독자가 [junior-read-prompt.md](junior-read-prompt.md)의 공통 기준에 아래 기준을 더한다. 링크는 이 스킬 디렉터리 기준이다.

## Check the execution contract

스킬은 설치된 플러그인에 있고 실행 위치는 사용자 프로젝트다. 다른 스킬은 이름이나 경로와 실행 지시가 있을 때만 읽을 수 있다고 본다.

- 입력이 무엇이며 호출자가 넘기는지 스스로 찾는지, 없을 때 어떻게 하는지 명확한가.
- 실행자와 다른 역할의 관계, 반환할 출력과 다음 단계가 명확한가.
- 상대 경로와 커맨드의 기준 디렉터리가 명확한가.
- 셸 블록의 변수가 대입되거나 치환할 자리로 명시됐는가. 블록 사이의 상태 공유 전제가 있는가.
- 명시한 커맨드와 인자만으로 목적이 달성되는가.

`groundwork:<이름>`은 로드 가능한 참조다. 문서가 실행을 요구하면 역할을 알 수 있어야 하며, 일반 도구·기술 지식을 다시 설명하도록 요구하지 않는다.

## Return contract findings

공통 반환 형식을 따르고 축은 실행계약·셸블록으로 표시한다. 빠진 계약 때문에 어느 첫 행동이 막히는지 적는다. PASS에는 확인한 계약 범위를 포함한다.
