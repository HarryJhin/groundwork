# Code reviewer prompt template

조율자가 아래 자리표시자를 채워 격리된 리뷰어에게 전달한다. 이 스킬 디렉터리 기준 파일이며 읽기 전용 리뷰에 쓴다.

```text
변경 요약: [DESCRIPTION]
요구·설계: [DESIGN_OR_REQUIREMENTS]
시작 커밋: [BASE_SHA]
끝 커밋: [HEAD_SHA]
리뷰 패키지 또는 diff 파일: [DIFF_FILE]

파일을 읽고 필요한 주변 코드·테스트와 요구를 대조한다. 파일이 없으면 해당 커밋 범위의 diff를 직접 확인한다.
워킹 트리·인덱스·HEAD·브랜치를 변경하지 않는다. 다른 리비전이 필요하면 별도 임시 체크아웃을 쓴다.
구현과 설계 자체의 문제를 구분하고 실제 근거가 있는 발견만 반환한다.

발견마다 file:line, 위반한 요구나 발생하는 문제, 사용자·운영 영향과 필요한 수정 방향을 적는다.
- Critical: 깨진 기능·보안·데이터 손실 문제
- Important: 누락 기능·아키텍처 문제·에러 처리·테스트 공백
- Minor: 진행을 막지 않는 개선

머지 가능 여부는 예·아니오·수정 후 중 하나와 기술 근거를 반환한다. 실행하지 않은 검증이나 확인하지 못한 범위는 밝힌다.
```

`DESCRIPTION`은 변경 요약, `DESIGN_OR_REQUIREMENTS`는 요구·설계 경로 또는 태스크 브리프, `BASE_SHA`와 `HEAD_SHA`는 범위 커밋, `DIFF_FILE`은 조율자가 만든 리뷰 패키지나 diff 파일 경로다.
