# dispatching-parallel-agents

## Separate independent investigations

입력은 테스트 출력·에러 로그에서 확인한 실패 목록이다. 조율자가 근본 원인과 공유 상태로 영역을 묶는다. 같은 원인·파일·자원에 의존하는 실패는 한 영역으로 다루고, 영역이 하나면 직접 조사한다.
설계의 구현 태스크 위임은 `groundwork:subagent-driven-development`를 따른다.

영역마다 서브에이전트에 범위·목표·에러 증거·변경 제약·반환할 발견과 수정 요약을 전달한다. 필요한 작업 경로를 명시하고 세션 전체 대신 해당 조사에 필요한 컨텍스트만 준다.
독립 영역의 조사는 동시에 시작한다. 모델과 컨텍스트 전달 방식은 실행 환경의 도구 안내를 따르고 공유 파일·상태를 동시에 바꾸게 하지 않는다.

반환된 수정과 발견을 대조해 통합하고 전체 테스트 스위트를 실행한다. 출력은 통합된 변경, 검증 결과와 남은 문제다.
